# Auth Flow

A multi-step authentication UI — login, registration, email verification, and password reset — demonstrating React Hook Form with Zod validation, shadcn/ui components, and Tailwind CSS v4.

**Live demo:** https://beardandbytes.dev/auth-flow

## Stack

React 19, TypeScript, Vite, Tailwind CSS v4, shadcn/ui, React Hook Form, Zod, react-router-dom

## Run it locally

```bash
npm install
npm run dev
```

## Where to look

- `src/pages/auth-flow/` holds the application code.
- `src/pages/auth-flow/components/` — shared UI primitives (shadcn-based input, label, button, password field).
- `src/pages/auth-flow/pages/` — individual route pages (login, register, verify-email, request-reset, password-reset).
- `src/pages/auth-flow/styles/design-system.css` — plain-CSS design tokens and component classes.
